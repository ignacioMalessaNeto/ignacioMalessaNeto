## Projetos em destaque

### [API de Gestão de Estoque](https://github.com/ignacioMalessaNeto/estoque)
API REST para controle de estoque: itens, categorias, endereços, entradas, saídas e histórico de movimentações, com autenticação por token.
`Laravel 11` `PHP 8.2` `MySQL`

### [Chat com IA](https://github.com/ignacioMalessaNeto/ia)
Chat web que envia perguntas a um back-end PHP, que funciona como proxy para a API da OpenAI. Mantém o contexto da conversa entre mensagens e deixa a chave de API apenas no servidor.
`PHP` `JavaScript` `OpenAI API`

### [Gestão de Biblioteca](https://github.com/ignacioMalessaNeto/desafio)
CRUD de autores e livros com paginação e layout responsivo (tabela no desktop, cards no celular). Roda localmente ou em container.
`React` `Vite` `Ant Design` `Docker`

### Food Explorer — [front-end](https://github.com/ignacioMalessaNeto/FoodExplorer) · [API](https://github.com/ignacioMalessaNeto/backendFoodExplorer)
Cardápio digital com dois perfis: o cliente busca pratos e faz pedidos; o administrador cadastra e edita pratos. API com autenticação JWT e upload de imagens.
`React` `Node.js` `Express` `Knex` `SQLite`
